# DOPE ENGLISH Flutter app

This directory is the new native UI target. The existing HTML/Capacitor app remains the working reference while screens and data contracts move across in small steps.

## Run

Install Flutter, then from this directory:

```bash
flutter pub get
flutter run
```

The first screen is the Grammar roadmap shell. Lesson content, Firebase authentication, vocab lookup, audio, and progress sync will be connected after the shell is verified on Android and iOS.
